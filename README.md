# KOMPOZA — прототипы сайта

Четыре направления сайта студии хоумстейджинга и дизайна интерьеров KOMPOZA.
В каждом варианте своя 3D-механика, решающая содержательную задачу, а не украшающая страницу.

**Демо:** откройте `index.html` — это хаб со ссылками на все версии.

## Версии

| | Направление | 3D-механика |
|---|---|---|
| **A** | Тёплый редакционный (коралл) | Предметы парят в разлёте и по скроллу стягиваются в собранный натюрморт |
| **B** | Инженерная точность (бордо) | Пустая квартира наполняется мебелью по скроллу, чек-лист отмечает позиции |
| **C** | Чертёж оживает (тёмная) | План квартиры поднимается из линий в объём, камера летит сверху в интерьер |
| **D** | Конфигуратор (светлая) | Клик по предмету убирает его из комплектации, смета пересчитывается |

Плюс `design/concepts.html` — сравнение двух концепций айдентики из презентации.

## Айдентика

Значения сняты пиксельно из `komoza_identity_pres.pdf`.
**Подписи hex в самой презентации неверны** (на стр. 11 и 31 указаны синие оттенки, не совпадающие с плашками) — ориентируйтесь на значения ниже.

**Концепция 1 — коралл:** `#FFFFFF` · `#EDE6E2` · `#000000` · `#FF9775`
Шрифты по презентации — Oceanic Grotesk + Oceanic Text (TypeToday, **платная лицензия**).

**Концепция 2 — бордо:** `#FFFFFF` · `#E6DDDB` · `#5B2824` · `#D1E6FD` · `#000000`
Шрифты — Golos Text + JetBrains Mono (открытая лицензия, полная кириллица, есть веб-начертания).

**Типографика во всех версиях единая — Golos Text + JetBrains Mono.** Варианты различаются палитрой, характером подачи и 3D-механикой, но не гарнитурами: так айдентика на сайте выглядит ровно так, как в презентации, без платных лицензий.

## Локальный запуск

Страницы используют ES-модули, поэтому открытие через `file://` не сработает — нужен любой статический сервер:

```bash
python3 -m http.server 4321
```

Затем откройте `http://localhost:4321/`.

## Публикация на GitHub Pages

Файл `.nojekyll` уже добавлен — без него GitHub игнорирует папки, начинающиеся с подчёркивания, и может ломать пути.

1. Создайте репозиторий и запушьте ветку.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

Все пути относительные, поэтому проект работает и в подпапке репозитория.

## Технические заметки

- Библиотеки (three.js, GSAP, Lenis) подключаются с CDN — сборка не нужна.
- Сцены собраны на примитивах, без загрузки 3D-моделей: быстрый старт и малый вес.
- Тени включены только у ключевого источника света и основных объектов.
- Уважается системная настройка «уменьшить движение»: анимации отключаются, сцены сразу показываются в собранном виде.

## Что нужно заменить перед запуском

- **Отзывы** — сейчас три реальных по смыслу, но неподтверждённых. Нужны настоящие с согласия авторов.
- **Цифры в сметах и на счётчиках** (230 проектов, суммы комплектации) — требуют сверки с фактическими данными студии.
- **Портрет основателя и часть интерьеров** — похожи на сток, ждут реальных съёмок.
- **Юридические данные в подвале** — заглушка, нужны реквизиты ИП и ссылка на документы.
